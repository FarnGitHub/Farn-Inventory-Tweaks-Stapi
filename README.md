# Mouse Tweaks Ornithe port

The unofficial port of MouseTweaks b1.7.3 RML TO Ornithe Loader

This one only use Accessor for Mixin so it has pretty good compatibility

## Requirement

- [Ornithe Loader for b1.7.3](https://ornithemc.net/download/)
- [Ornithe Standard libraries](https://modrinth.com/mod/osl)
